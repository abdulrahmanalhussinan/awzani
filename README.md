# أوزاني

حسبة أوزان النادي بدون اشتراك: اختر القسم (الصدر، الظهر، الأرجل، الأكتاف، الذراع، البطن، الكارديو)، ثم الجهاز، وسجّل الوزن والعدات والجلسات.

- تبدأ باسمك، وفوق يطلع اليوم وتاريخه، وكم تمرين خلصت ومجموع الجلسات والعدات ووزن جسمك.
- يحسب المجموع (الوزن × العدات × الجلسات) لكل جهاز ويقترح متى تزيد الوزن.
- يحسب أقراص البار لكل جهة، بالكيلو أو الرطل.
- صورة لكل جهاز بجانب اسمه، وفي صفحة الجهاز تتبدل بين بداية الحركة ونهايتها (من free-exercise-db، ملكية عامة).
- سجل لكل جهاز مع رسم للتقدم، وسجل عام حسب اليوم.
- تقدر تضيف أجهزة وأقسام نادك.
- عربي أو English: زر اللغة في شاشة البداية والرئيسية والإعدادات، والصفحة تقلب اتجاهها.
- كل البيانات في جوالك (localStorage)، مع نسخة احتياطية تنزّلها وترجعها.
- يشتغل بدون نت بعد أول فتح، ويتثبت على الشاشة الرئيسية.
